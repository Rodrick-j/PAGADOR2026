# Plataforma P.A.G.A.D.OR. (server)

Plataforma virtual para atencion a procesos administrativos de la G.A.D.OR.

## Herramientas utilizadas:

| Tecnología | Versión | Descripción                                                                     |
| ---------- | ------- | ------------------------------------------------------------------------------- |
| Node       | ^20.18  | Entorno de desarrollo de JavaScript.                                            |
| Typescript | ^3.9    | Lenguaje de programación libre y de código abierto construido sobre JavaScript. |
| MySQL      | ^5.7    | Base de datos relacional.                                                       |
| Express    | ^4.17   | Framework de NodeJS.                                                            |
| Git        | ^2.20   | Sistema de control de versiones distribuido de código abierto.                  |
| Eslint     | ^6.6    | Herramienta de linting para JavaScript.                                         |

## Servicios de Docker

| Servicio                | Descripción                                              |
| ----------------------- | -------------------------------------------------------- |
| Caprover                | Para el despliegue de los servicios server y admin.      |
| FTP                     | Como unidad de almacenamiento de archivos.               |
| MySQL                   | Como unidad de almacenamiento para la base de datos.     |
